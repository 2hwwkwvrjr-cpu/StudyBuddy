# StudyBuddy

StudyBuddy ist eine Lernplanungs-App für Studierende.

Funktionen:
- Aufgaben hinzufügen, bearbeiten und löschen
- Dringlichkeit automatisch berechnen
- Aufgaben automatisch sortieren
- Lernzeit erfassen
- Timer verwenden
- automatisches Wochenziel berechnen
- Kalender mit Deadlines
- Dark Mode

Dateien:
- studybuddy.html = Benutzeroberfläche
- studybuddy.js = Logik und Algorithmen
- studybuddy_tasks.json = Ausgangsdaten
